## How to use this site

1. Choose a topic from the navigation.
2. Understand the concept and the problem it solves.
3. Review internal working and code examples.
4. Attempt interview questions before revealing answers.
5. Explain the topic using a practical project scenario.

## Learning format

Each topic will eventually include a simple explanation, purpose, internal working, examples, trade-offs, common mistakes, interview questions, and real-world scenarios.
