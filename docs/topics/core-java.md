## Recommended study method

For every lesson:

1. Read the explanation and note the exact rule.
2. Type and run the code. Predict the output first.
3. Change one line and observe what changes.
4. Answer the interview questions aloud in 60–90 seconds.
5. Complete the practice task without copying the solution.

This is the first detailed Core Java batch. Further lessons will cover the remaining language features and common interview edge cases.
