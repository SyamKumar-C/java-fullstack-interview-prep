# Core Java

This section covers the Java language fundamentals that commonly appear in full-stack Java interviews.

## Learning order

1. [Object-oriented programming](core-java/oop.md)
2. Classes, objects, and constructors
3. Overloading and overriding
4. Abstract classes and interfaces
5. Default and static methods in interfaces

The remaining lessons will be added in this section as Phase 2 progresses.

## How to study

For each topic, first understand the concept, then run the code example, and finally answer the interview questions without looking at the explanation.
