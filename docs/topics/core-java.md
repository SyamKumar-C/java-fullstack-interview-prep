# Core Java

This section covers the Java language fundamentals that commonly appear in full-stack Java interviews.

## Learning order

1. [Object-oriented programming](core-java/oop.md)
2. [Classes, objects, and constructors](core-java/classes-objects-constructors.md)
3. [Overloading and overriding](core-java/overloading-vs-overriding.md)
4. [Abstract classes and interfaces](core-java/abstract-classes-vs-interfaces.md)
5. [Default and static methods in interfaces](core-java/interface-default-static-methods.md)

## How to study

For each topic, first understand the concept, then run the code example, and finally answer the interview questions without looking at the explanation.
