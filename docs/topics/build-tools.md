# Build Tools and Git

Build tooling and version control are part of daily Java development and are common interview topics.

## Lessons
1. [Maven and Gradle](build-tools/maven-gradle.md)
2. [Git fundamentals and team workflows](build-tools/git-workflows.md)

## What to practise
- Explain Maven lifecycle phases and Gradle task execution.
- Inspect transitive dependency conflicts.
- Resolve a merge conflict and explain merge vs rebase.
- Safely undo a commit that has already been pushed.
