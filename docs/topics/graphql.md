# GraphQL

GraphQL is useful when clients need flexible data selection across related domains. Learn the schema model, resolver execution, performance controls, and federation trade-offs.

## Lesson
1. [GraphQL fundamentals, Spring GraphQL and federation](graphql/graphql-federation.md)

## What to practise
- Design a schema for customers and orders.
- Explain query vs mutation and resolver responsibilities.
- Identify an N+1 resolver problem and explain DataLoader.
- Draw a federated graph with independently owned subgraphs.
