# Study Roadmap

Priorities:
- **P1:** Must know; commonly tested.
- **P2:** Important; common follow-up topics.
- **P3:** Advanced or role-dependent.

| Category | Coverage |
|---|---|
| Core Java | OOP, language fundamentals, strings, exceptions, generics |
| Collections | List, Set, Map, hashing, sorting, iteration |
| Streams | Functional interfaces, stream operations, collectors |
| Concurrency & JVM | Threads, synchronization, virtual threads, memory, GC |
| Spring | IoC, beans, Boot, configuration, AOP, transactions |
| Persistence | JPA, Hibernate, entity lifecycle, fetching, query tuning |
| SQL | Joins, CTEs, indexes, query plans, transactions |
| APIs & Security | REST, validation, authentication, authorization |
| Microservices | Service boundaries, Kafka, resilience, distributed data |
| Angular | Components, DI, routing, forms, change detection |
| Frontend foundations | JavaScript, TypeScript, RxJS, browser fundamentals |
| System design & DevOps | Design trade-offs, AWS, Docker, CI/CD, observability |

Use the Topics navigation to browse the category list.

## Audit additions
The detailed lessons now also cover Spring Boot auto-configuration/testing and operational features; JPA projections and batching; SQL constraints/NULL/views; OAuth/OIDC and rate limiting; Kafka fundamentals; Angular directives/DI/routing; collection immutability; browser storage; system design capacity, file ownership, and Docker/CI/CD.
