# Interview Answer Format

Prepare each topic using this structure.

## 1. Definition
Explain the concept in one or two simple sentences.

## 2. Why it matters
Describe the problem it solves.

## 3. How it works
Explain the key internal steps or rules.

## 4. Example
Show a short, readable code example.

## 5. Trade-offs
Explain when to use it, when not to use it, and common pitfalls.

## 6. Follow-up questions
Prepare likely interviewer follow-ups.

## 7. Real project example
Connect the concept to a Spring Boot, Angular, SQL, or microservices scenario.
